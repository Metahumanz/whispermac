# WhisperMac v0.3.0

发布日期：2026-11-03

本版重点修复长录音中字幕连续几分钟甚至几十分钟重复的问题，并加入可保存的上下文选项和完整诊断日志。同时完善模型下载源选择、文件夹导入和 VAD 模型路径管理。

## 字幕识别与重复修复

- 新增「调整选项 → 转写 → 跨窗口文字上下文」。默认关闭，选择会自动保存，并显示在任务摘要中。
- 关闭时使用 `--max-context 0`，不再把上一段识别出的文字作为后续音频窗口的提示，减少错误短语不断传播造成的重复循环。原有解码失败回退机制继续保留。
- 需要前后用词更连贯时可以开启该选项；开启后也可能重新增加重复风险。任务开始时会固定本次设置。
- 使用 large-v3 并开启 VAD，完整重跑两份约 95 分钟、92 分钟的英语录音，原来约 88 分钟和 54 分钟的持续循环均未再出现，分别生成 852 条、851 条字幕。时间戳没有倒退。

## 可追踪的运行日志

- 每批任务会在 `~/Library/Logs/WhisperMac/` 保存命令参数、原始识别输出、错误输出以及退出结果，应用关闭后仍可排查。
- 日志文件仅当前用户可读写；日志写入失败不会中断转写。
- 日志包含文件路径和字幕文本，只保存在本机，可按需手动删除。

## 模型下载与 VAD 配置

- 支持官方 Hugging Face、HF-Mirror 和自定义兼容端点；所选来源统一用于模型、Core ML encoder、Silero VAD 和元数据下载。
- `WHISPERMAC_HF_ENDPOINT` 环境变量仍具有最高优先级。
- 自动发现的 VAD 模型现在显示实际路径，同时继续保持自动解析模式；手动路径失效时仍保留路径信息，便于定位问题。
- 修正下载按钮在不同端点和下载状态下的可用性。

## 文件与文件夹导入

- 拖入文件夹可递归添加其中支持的媒体，跳过隐藏项、应用包和目录符号链接。
- 按磁盘的文件名大小写规则去重，重复文件与新文件混合添加时只加入新文件。
- 目录扫描在后台执行，并保持并发添加的顺序；只添加了重复文件时会给出明确反馈。

## 自动构建与发布

- 版本标签触发 GitHub Actions，依次执行测试、构建固定版本的 whisper.cpp、打包应用、校验签名和 SHA-256，全部通过后公开 Release。
- 发布正文读取仓库内的详细说明，不再只有提交范围和跳转链接。
- 固定应用及运行时的 macOS 14 最低目标，校验 Apple Silicon 架构；校验文件使用下载包的文件名，可直接执行 `shasum -a 256 -c *.sha256`。

## 下载与升级

- 下载 `WhisperMac-v0.3.0-app-only-macos-arm64.zip`，解压后替换「应用程序」中的 WhisperMac。
- 面向 Apple Silicon Mac，最低系统目标为 macOS 14。最低系统版本尚未在实机上单独验证。
- 安装包包含应用和 whisper.cpp 运行时，不包含体积较大的识别模型。已有模型与设置可继续使用，新用户可在应用中下载模型。
- 安装包采用临时签名，尚未经过 Apple 公证，首次打开可能需要在系统「隐私与安全性」中允许打开。

## 已知限制

- 关闭文字上下文不能消除所有幻觉，也可能降低前后术语的一致性。以上验证针对长循环，不代表逐词准确率评估。
- turbo 关闭 VAD 的补测中，片头 90 秒仍出现三次重复短语；开启 VAD 后该片头重复消失。处理停顿较多的长录音时，建议保留 VAD。
- VAD 也可能漏掉轻声或歌声；可按录音情况调整阈值或关闭后重试。
